## 1. 变更摘要

### 1.1 颜色统一（按你的要求）

`MoneyText` 的支出从「中性色」改成语义红，收入仍是语义绿，转账保持中性。
只改金额文字颜色，**表格行背景不动**。日历与记录表格现在同一套口径。

### 1.2 托盘常驻

| 文件 | 内容 |
| --- | --- |
| `src/main/tray.ts` | 托盘创建、右键菜单、左键切换显示 / 隐藏 |
| `src/main/app-state.ts` | `isQuitting` 标志：区分「点 X」和「真的退出」 |
| `src/main/window.ts` | `close` 事件拦截：不是退出流程就 `preventDefault()` + `hide()` |
| `src/main/index.ts` | `window-all-closed` 不再退出；`before-quit` 里标记退出并销毁托盘 |

行为：

- 启动后托盘图标常驻右下角，悬停提示「记账簿」；
- 点窗口右上角 **X → 窗口隐藏，进程继续运行**（不是退出）；
- **左键单击托盘图标**：显示 / 隐藏主窗口；
- **右键菜单**：`打开主界面` / `退出`；`退出` 才真正结束进程；
- 再次双击快捷方式启动时，因为有单实例锁，会唤回已经运行的那个窗口，不会再开一个。

### 1.3 图标

`scripts/make-icons.mjs` 手写 PNG 编码 + ICO 打包，不引任何图形库：

- 设计：青绿圆角底 + 白色账本页 + 三条账目线 + 一枚橙色硬币；
- 应用图标 `resources/icons/icon.ico`（16/24/32/48/64/128/256 七个尺寸），同时复制一份到 `build/icon.ico` 供 electron-builder 使用；
- 托盘图标 `resources/icons/tray.ico`（16/24/32），另有 `tray.png` / `tray@2x.png` 预览；
- 尺寸按 4 倍超采样绘制后降采样，小尺寸下边缘不毛糙。

要改图标：改 `scripts/make-icons.mjs` 里的绘制函数，跑 `npm run icons` 重新生成。

### 1.4 打包配置

新增 `electron-builder.yml` 与 `scripts/build-win.mjs`（`npm run build:win`）。

三个关键点，都是为了在这台机器上能顺利出包：

| 配置 | 原因 |
| --- | --- |
| `npmRebuild: false` | 本机没有可用的 MSVC，better-sqlite3 不能重新编译；用已经按 Electron ABI 预编译好的 `.node` |
| `asarUnpack: node_modules/better-sqlite3/**` | 原生模块必须解包到 asar 外，否则运行时 require 不进来 |
| `electronDist: node_modules/electron/dist` | 直接用本地已下载的 Electron，不再拉一次 100MB |

工具链（winCodeSign / wix / nsis）默认走 npmmirror 镜像下载，直连 GitHub 会超时。
可用 `ELECTRON_BUILDER_BINARIES_MIRROR` 覆盖。

## 3. 怎么双击运行

### 方式一：免安装版（最省事，推荐先试这个）

1. 打开 `release` 文件夹；
2. 双击 `daily-ledger-0.1.0-portable.exe`；
3. 首次启动会出现引导页，选一个数据目录，点「开始使用」。

### 方式二：MSI 安装包

1. 双击 `daily-ledger-0.1.0-installer.msi`；
2. 按提示下一步，装完在桌面和开始菜单会有「记账簿」快捷方式；
3. 双击快捷方式启动。

### 方式三：NSIS 安装包

1. 双击 `daily-ledger-0.1.0-setup.exe`；
2. 可以自己选安装目录；
3. 装完同样有桌面 / 开始菜单快捷方式。

> 三个包都没有做代码签名（没有证书），Windows SmartScreen 可能提示「未知发布者」，
> 点「更多信息 → 仍要运行」即可。这是签名缺失导致的，不是程序有问题。

## 4. 怎么验证托盘

1. 启动应用（上面任一方式）；
2. **看右下角**：任务栏通知区域应出现青绿色账本图标（Win11 可能收在「^」里，可以拖到常显）；
3. **测试 X**：点窗口右上角 `✕` —— 窗口消失，**任务栏里的应用图标也消失，但托盘图标还在**；
4. **左键单击托盘图标** —— 主窗口回来；
5. **右键单击托盘图标** —— 菜单里有 `打开主界面` 与 `退出`；
6. 点 `打开主界面` —— 窗口回来；再点 X 隐藏；
7. 点 `退出` —— 托盘图标消失，任务管理器里不再有「记账簿」进程。

第 3 步是最容易看错的：**X 不是最小化到任务栏，而是收进托盘**，任务栏图标会一并消失。
