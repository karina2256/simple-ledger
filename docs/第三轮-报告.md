## 1. 做了什么

### 1.1 纯函数层（`src/shared/`）

| 文件 | 内容 |
| --- | --- |
| `date.ts` | 日期工具：`YYYY-MM-DD` 字符串运算、周一为周起点、ISO 周序号、月格范围、逐日枚举。全程本地时间构造 `Date`，不走 `new Date('YYYY-MM-DD')`，不会被时区带偏 |
| `aggregate.ts` | `sumRange` / `sumByMonth` / `sumByWeek` / `fillDays`：四级视图共用一套汇总口径 |
| `recurring.ts` | `expandOccurrences` 把周期规则展开成具体日期；`nextOccurrence`；频率中文描述 |

关键点：**年 / 月 / 周的数字都由同一份「按天聚合」滚出来**，所以月视图加起来一定等于年视图，不会出现两套 SQL 各算各的。

### 1.2 主进程

| 文件 | 内容 |
| --- | --- |
| `db/repositories/records.repo.ts` | 新增 `dayTotals(from, to)`：按天聚合收入 / 支出 / 转账 / 笔数，只返回有记录的天 |
| `db/repositories/recurring.repo.ts` | 新增：周期规则的完整增删改查 + 启停；`next_date` 只在写库时按 `start_date` 推一次，作为缓存 |
| `ipc/calendar.ts` | `calendar:summary`：一次往返返回「日聚合 + 周期发生点」；区间上限 400 天 |
| `ipc/recurring.ts` | 规则增删改查与启停，带完整校验（金额、频率、间隔、起止日期、账户、分类） |

### 1.3 界面

| 文件 | 内容 |
| --- | --- |
| `features/calendar/CalendarPage.tsx` | 路由容器：解析 `?view=&date=`、面包屑、粒度切换、前后翻页、今天 |
| `features/calendar/views.tsx` | 年 / 月 / 周 / 日四个视图 |
| `features/calendar/parts.tsx` | 三色行、⟳ 标记、周期条目 |
| `features/calendar/useCalendarData.ts` | 数据获取：一次 `calendar:summary`，周 / 日视图再补一次明细 |
| `features/records/RecordTable.tsx` | 从记录页抽出的表格，记录页与日视图共用 |
| `features/records/DeleteRecordModal.tsx` | 抽出的删除弹窗，两处共用 |
| `features/recurring/RecurringPage.tsx` | 周期规则最小入口（本轮范围 A） |

路由状态全部放在 URL（`#/calendar?view=month&date=2026-09-26`），刷新、返回、面包屑跳转都一致，组件不存副本。

### 1.4 交互细节

- **面包屑**：`2026年 › 9月 › 第 39 周 › 9月26日 周六`，每一段都可点，点了切到那一级且锚点日期不变。
- **进入下一级**：年视图点月格 → 月视图；月视图点日期 → 日视图、点左侧「第 N 周」→ 周视图；周视图点日期 → 日视图。
- **点格新增**：月视图格子悬停出现「＋」，周视图列头有「＋」，日视图有「＋ 记一笔」；点了直接打开表单，日期预填成那天。年视图不提供直接新增（避免记错月份）。
- **周期标记 `⟳`**：年视图月格标题右肩、月视图日期格右上角、周视图列头、日视图记录上方，四处都在；悬停显示规则名与金额。周视图列内与日视图还会用虚线卡片列出周期项，并明确写「仅标记，未生成记录」。
- **转账**：不进任何格子的收支，日视图底部单独提示「另有转账 ¥xxx（不计入收支）」。

### 1.5 深色模式三色

`--c-income` / `--c-expense` 两个语义色变量，浅色与深色各一套，全局 `--c-muted` 按方案从 `#6B7A88` 调到 `#5F6E7C`：

| 语义 | 浅色（白底） | 对比度 | 深色（卡片 `#1B2128`） | 对比度 |
| --- | --- | --- | --- | --- |
| 收入 | `#1F7A4D` | 5.32:1 | `#6FCF9A` | 8.55:1 |
| 支出 | `#B23F38` | 5.74:1 | `#F0908A` | 7.00:1 |
| 净变化 | 正绿 / 负红 / 零 `#5F6E7C` | 5.24:1 | 零 `#93A1AE` | 6.7:1 |

净变化一律带显式 `+` / `−` 符号，不靠颜色单独表意。

然后：

1. **四级视图**：左侧点「日历」→ 顶部 `年 月 周 日` 四处切换，面包屑逐级变长，点面包屑任意一段能跳回那一级。
2. **对数字**：月视图某天的数字，和记录页筛那天的手算结果比一比；年视图某月格子 = 该月月视图的合计。
3. **周期标记**：`周期记账` 页建一条规则（比如「每月 1 号 房租 2000」），回到日历看 `⟳` 是否出现在年格、日期格、周列头、以及日视图的记录上方。
4. **点格新增**：月视图某天悬停点「＋」，表单日期应已填成那天；保存后那天的数字立刻变，人还停在月视图。
5. **深色模式**：右上角切「深色」，日历里收入（绿）、支出（红）、净变化（正绿负红零灰）都要能一眼分清。
6. **转账**：记一笔转账，确认它不出现在任何格子的收支里，日视图底部单独提示。
