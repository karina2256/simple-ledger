# 官网发布与「能被搜到」操作手册

网站已经做好了，在 `website\` 目录里。这一份是**你要亲手做的部分**，按顺序走。

---

## 零、先本地看一眼

```powershell
npm run site        # 起本地预览，然后浏览器打开 http://127.0.0.1:5173
npm run verify:site # 自检：SEO 元素、链接、资源、体积（当前 32/32 通过）
```

## 一、下载链接（必做，否则下载按钮只会弹提示）

安装包 116–127 MB，**不能和网页放一起**（代码托管平台都有仓库体积限制）。三条路，选一条：

### 方案 A：GitHub Releases（免费，推荐先用这个）

1. 注册 GitHub 账号 → 新建一个仓库（public），例如 `jizhangbu`。
2. 把 `website\` 里的全部文件推上去（或者只在 Releases 里传安装包，网页另放，见方案 B）。
3. 进仓库 → **Releases → Draft a new release**：
   - Tag 填 `v0.1.0`；
   - 把 `release\` 里的三个安装包拖进附件区上传；
   - 发布。
4. 上传完每个附件都有一个直链，形如：
   ```
   https://github.com/你的账号/jizhangbu/releases/download/v0.1.0/daily-ledger-0.1.0-portable.exe
   ```
5. 把三个直链填进 `website\main.js` 顶部的 `DOWNLOADS`：
   ```js
   var DOWNLOADS = {
     portable: 'https://github.com/.../daily-ledger-0.1.0-portable.exe',
     setup:    'https://github.com/.../daily-ledger-0.1.0-setup.exe',
     msi:      'https://github.com/.../daily-ledger-0.1.0-installer.msi'
   }
   ```

**好处**：免费、不限速不明显、有版本历史，而且**以后可以做自动更新**（读 Release 的版本就能提示新版）。
**坏处**：国内部分网络访问 GitHub 不稳定。

### 方案 B：对象存储（国内访问稳，几毛钱一个月）

1. 开通 **阿里云 OSS / 腾讯云 COS / Cloudflare R2** 任一个（R2 出网免费最多）。
2. 建一个 Bucket，**权限设为「公共读」**。
3. 上传三个安装包，拿到形如 `https://你的bucket.oss-cn-xxx.aliyuncs.com/daily-ledger-0.1.0-portable.exe` 的地址。
4. 填进 `main.js` 的 `DOWNLOADS`。

**好处**：国内下载快、稳。
**坏处**：要实名、要付费（金额很小）。

### 方案 C：网页和安装包放同一个目录

如果只给自己人用（比如放在内网或网盘同步目录），直接把三个安装包拷到 `website\` 下，
`DOWNLOADS` 里填**相对文件名**即可：

```js
var DOWNLOADS = { portable: 'daily-ledger-0.1.0-portable.exe', setup: '...', msi: '...' }
```

## 二、把网站放上网（必做）

### 托管选择

| 方案 | 费用 | 国内访问 | 自定义域名 | 说明 |
| --- | --- | --- | --- | --- |
| **Cloudflare Pages** | 免费 | 一般 | 支持 | 拖拽文件夹即可，自带 HTTPS，最省事 |
| **Vercel / Netlify** | 免费额度 | 一般 | 支持 | 同样拖拽部署 |
| **阿里云 OSS 静态网站** | 几毛/月 | 快 | 支持 | 国内访问最快，但要实名 + 备案（用自己域名时） |
| **腾讯云 COS 静态网站** | 同上 | 快 | 支持 | 同上 |

**最快路径（10 分钟）**：Cloudflare Pages → Create project → 直接上传 `website` 文件夹 → 得到一个 `xxx.pages.dev` 地址，立刻能访问。

### 域名（「能被搜到」的关键）

**没有域名的站点，搜索引擎基本不会当成正经站点。** 免费子域名也能被收录，但权重低、分享出去也不像产品。

1. 买域名：Namecheap / Cloudflare Registrar / 阿里云万网，`.com` 约 ¥60–90/年，`.app`/`.dev` 类似。
2. 在托管平台里绑定自定义域名，按提示改 DNS。
3. **用国内服务器/OSS 且用自己域名时，需要 ICP 备案**（个人约 1–3 周）。用 Cloudflare Pages + 海外域名则不需要备案。

买了域名后，把 `website\` 里这三处 `example.com` 换掉：
- `index.html` 的 `canonical` 与 `og:url`
- `robots.txt` 里的 `Sitemap:` 行
- `sitemap.xml` 的 `<loc>`
（`npm run verify:site` 会提醒你还有哪些没换。）

## 三、「别人也能搜到」具体怎么做

搜索排名没有捷径，但下面这些是**确定性有效**的，照着做就行。

### 第 1 步：让搜索引擎知道你存在（提交站点地图）

| 搜索引擎 | 入口 | 做什么 |
| --- | --- | --- |
| **Google** | search.google.com/search-console | 添加资源 → 验证所有权（DNS TXT 或 HTML 文件）→ 提交 `sitemap.xml` → 用「网址检查」请求收录首页 |
| **Bing** | bing.com/webmasters | 同上（Bing 在国内可直接访问，且被部分国产引擎参考） |
| **百度** | ziyuan.baidu.com | 添加站点 → 验证（需上传验证文件到网站根目录）→ 提交 sitemap → 用「普通收录 → 手动提交」推首页 URL。**注意：百度要求站点有 ICP 备案才给较好收录**，用海外托管会明显吃亏 |

提交后一般几天到几周开始收录。**先提交首页 URL**，不要等自然发现。

### 第 2 步：技术面已经替你做好了（不用管）

站点已包含：

- `<title>` 与 `<meta description>`（26 字 / 95 字，长度合适）
- `<meta name="keywords">`、`canonical`、`robots: index, follow`
- **Open Graph 标签** —— 分享到微信/QQ/Twitter 会有标题、描述、预览图
- **结构化数据 `SoftwareApplication`** —— 让引擎知道这是「Windows 财务软件、免费」
- `sitemap.xml` + `robots.txt`
- 语义化标签（`h1` 唯一、`h2` 分层）、图片 `alt`、懒加载
- 纯静态、零 JS 依赖、首屏 HTML 21 KB —— 加载快，移动端友好
- **正文 2700+ 字**，包含 6 组问答（长尾关键词来源）

### 第 3 步：内容策略（真正决定能不能被搜到）

别人搜的是**问题**，不是你的产品名。围绕这些词写内容，比堆关键词有效得多：

- 「微信账单怎么导出成 Excel」
- 「记账软件哪个不上传数据 / 不联网」
- 「本地记账软件推荐 Windows」
- 「账单截图怎么自动记账」
- 「记账数据存在哪里 会不会被上传」

**可执行动作**：

1. **在官网加一个「使用教程」栏目**（每篇一个 HTML 页面），把上面的问题各写一篇 800–1500 字的真实教程。
   我可以帮你写并做成同样的页面风格 —— 说一声就做。
2. **发到这些地方（都能被搜到，且会带来第一批用户）**：
   - 少数派（sspai.com）—— 软件推荐类文章收录极好
   - V2EX「分享创造」节点
   - 小众软件（appinn.com）—— 可投稿，专门收这类工具
   - 知乎回答「有哪些好用的记账软件」
   - B 站/小红书：录一段「截图丢进去自动记账」的 15 秒视频，短视频带来的量往往比搜索还大
3. **保持更新**：搜索引擎偏好持续更新的站点。每发一个版本，写一条更新日志页（`changelog.html`），也是新内容。

### 第 4 步：加速收录的小技巧

- 在 GitHub 仓库 README 里放官网链接（GitHub 权重高，能带过去）
- 在软件「设置 → 关于」里放官网链接（用户点了、分享了，都是外链）
- 把官网链接发到任何你已有的公开主页
- 百度站长平台有「快速收录」额度，提交后几天内可能收录

## 四、发布前检查清单

```powershell
npm run verify:site    # 32 项自检
```

- [ ] `website\main.js` 里三个 `DOWNLOADS` 链接已填真实地址，且**点开能下载**
- [ ] `example.com` 全部换成真实域名（自检会提醒）
- [ ] `privacy.html` 的联系方式换成你的真实邮箱
- [ ] 网站已部署，HTTPS 正常
- [ ] 提交了 sitemap 到 Google / Bing（有备案的话再加百度）
- [ ] 用手机打开一次，确认版式没问题
- [ ] 分享链接到微信，确认预览卡片有标题和图片
- [ ] 三个安装包都下载一次并**真的装上**（尤其验证签名缺失时的 SmartScreen 提示文案与说明一致）
